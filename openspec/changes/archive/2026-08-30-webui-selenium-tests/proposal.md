## Why

Требуется автоматизированное тестирование веб-интерфейса brahma-webui для проверки корректности работы регистрации и удаления терминалов через UI. Текущая покрытие тестами ограничено unit-тестами, необходима интеграционная проверка End-to-End работы формы с реальными данными в базах данных.

## What Changes

- Создать новый проект `brahma-webui-test` с Selenium/Selenide тестами
- Реализовать 4 тест-сценария:
  1. Регистрация терминала через форму с location=Москва, проверка в обеих формах
  2. Удаление терминала через форму, проверка отсутствия в обеих БД
  3. Регистрация терминала через GRPC форму с location=Berlin, проверка статуса Rejected
  4. Очистка данных после тестов (удаление из обеих БД)
- Использовать тестовый терминал TERM-00027 с уникальной моделью
- Запуск тестов на Firefox

## Capabilities

### New Capabilities
- `brahma-webui-selenium-tests`: Автоматизированное тестирование веб-интерфейса регистрации терминалов через Selenium/Selenide

### Modified Capabilities
- `brahma-webui`: Добавляется интеграционное тестирование существующего функционала (не меняет требования)
